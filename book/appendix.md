# Appendix: Preparing this resource with VS Code and Codex

This appendix explains how this book has been prepared and maintained. It is intended as a transparent record of the role of generative AI in the resource.

## Starting point: independently developed teaching material

The course materials, teaching sequence, practical activities, examples, and assessment context behind this book were developed independently over several years of teaching LIFE733. They reflect decisions about what students need to learn, the order in which ideas are introduced, the biological examples used, and the support offered in workshops.

GAI did not replace that teaching experience or make the academic decisions for the module. It was used to help turn, revise, and maintain this material as a coherent online book.

## Tools used

### VS Code

VS Code was used as the main editor for the project. This record will be maintained in Markdown files in the [`book/` folder](https://github.com/rtreharne/python-for-life-sciences/tree/main/book). VS Code was used to:

- open and navigate the project files
- edit chapter text, configuration, and links
- inspect changes to Markdown and YAML files
- use the integrated terminal to build and check the book
- review generated pages locally before publication.

The book is built with MyST and Jupyter Book. The build command checks the Markdown structure, internal references, and executable Python examples. The static site is then published through the repository's normal deployment process.

### Codex

Codex was used as a coding and editing assistant within the project workspace. It was asked to work on clearly scoped tasks, including:

- drafting, restructuring, and revising explanatory prose
- creating the Course Setup, GAI, Week 6, and appendix material
- checking consistency between chapters, the table of contents, folder guidance, and solutions
- identifying UK and US spelling differences
- preparing precise edits for review before they were committed

Codex was also used to update selected Canvas pages through the course API when instructed to do so. These updates were limited to the LIFE733 course and included reading the existing HTML first so that new content matched the established page style.

## Model record

The model used for the Codex-assisted work recorded here is **GPT-5**, accessed through Codex. Codex is a coding agent based on GPT-5 and was used for the drafting, editing, checking, and command-running described above.

This appendix does not claim that every word in the book was generated by GPT-5, nor that GAI was the sole source of any chapter. Much of the book is independently developed teaching material, and human editorial judgement determines what remains in the published resource.

If a different model or GAI platform is used to make future substantive changes to the book, this record will be updated before publication with the platform, model where known, and its role in the work.

## What GAI was not asked to decide

GAI was not treated as the authority on:

- the learning outcomes or assessment requirements of LIFE733
- what students are expected to understand independently
- University policy or assessment rules without checking the relevant source

The teaching team remains responsible for the accuracy, suitability, accessibility, and academic integrity of this resource.

## Human review before publication

All generated content has been reviewed by a human before publication. Review includes checking that the material:

- is accurate enough for its teaching purpose
- matches the intended level and sequence of the course
- does not introduce unnecessary complexity or unsupported claims
- preserves working code, filenames, commands, and links
- follows the University's requirements for teaching and assessment.

## Why this is different from student assessment

Staff may use professional tools, including GAI, to create and maintain teaching resources. Students may also use GAI in the ways permitted by the University and by each assessment brief. The difference is the purpose of the work.

Your assessed work is evidence of your own learning. You must be able to explain your approach, test your code, document meaningful GAI use, and follow the assessment requirements. A tool may support that process, but it cannot demonstrate your understanding for you.

For the full student guidance, return to [Using Generative Artificial Intelligence (GAI)](gai.md).
