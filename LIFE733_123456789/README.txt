Student ID: 123456789

This folder demonstrates the required final submission layout.

The downloads/ folder contains the original Project 1 and Project 2 ZIP files
generated for this student ID. Their contents have been extracted into
portfolio/project-1/ and portfolio/project-2/.

The week-* folders are intentionally empty: add your weekly problem solutions
and any associated input data to the matching week folder.

The Project 1 result files and Project 2 output/ folder are intentionally
empty. Complete the supplied Python templates yourself, then run the project
test scripts to create the required outputs and test transcripts.

Do not submit this example unchanged. Before the Canvas deadline, replace it
with your own complete LIFE733 folder and create one ZIP of that folder.
